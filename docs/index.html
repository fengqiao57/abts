为什么是阿B听书

免登录

不登录即可搜索、收听、收藏、记录进度；扫码登录仅用于同步头像昵称。

无广告

没有广告、没有会员、没有弹窗，打开就能听。

专注收听

断点续播精确到秒；睡眠定时、后台播放与锁屏控制。

能听什么，怎么听

听什么

有声小说、评书、相声、广播剧；分类浏览与精选主播直达。

怎么听

分P连播、±15 秒快进退；来电自动暂停，打断结束自动续播。

书架

收藏、继续收听、最近收听，进度精确到秒；深色模式跟随系统。
