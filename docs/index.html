为什么是阿B听书

三条贯穿始终的原则，不多也不少。

免登录

不登录即可搜索、收听、收藏、记录进度。扫码登录仅用于同步昵称头像与提升搜索稳定性，随时可退出。

无广告

没有广告、没有会员、没有弹窗，也没有开屏等待。打开就能听，听到哪算哪。

专注收听

为长时间听书优化：分P连播、断点续播精确到秒、睡眠定时、后台播放与锁屏控制，通勤和睡前都省心。

能听什么，怎么听

内容来自 B 站公开视频的音频轨道，搜索自动限定在「有声小说」范围。

发现与搜索

  • 分类浏览：热门推荐 / 广播剧 / 评书 / 相声 / 悬疑 / 玄幻仙侠 / 名著悦读
  • 精选主播：单田芳、刘兰芳、郭德纲、周建龙、紫襟、王明军、光合积木、729声工场 等，一点直达
  • 过滤解说、漫推、短视频等无关内容
  • 分类结果本地缓存，减少重复请求

播放体验

  • 分P 即章节：自动连播、上/下一章、±15 秒快进快退
  • 断点续播精确到秒，退后台、切章节、退出应用都会保存
  • 睡眠定时：10/15/30/45/60 分钟、2 小时，或自定义 1~720 分钟
  • 音频焦点：来电自动暂停，打断结束自动续播
  • 后台播放：通知栏与锁屏可控制，暂停后通知不消失

书架与其它

  • 书架收藏、继续收听、最近收听 均显示精确进度
  • 章节列表：已听章节置灰，支持正序 / 倒序
  • 外观模式：跟随系统 / 浅色 / 深色
  • 检查更新：一键比对 GitHub Releases
  • 分享原作品链接

不需要。不登录即可搜索、收听、收藏、记录进度；扫码登录仅用于同步昵称头像与提升搜索稳定性。

支持。通知栏与锁屏均可控制播放与切章，睡眠定时到点自动暂停。
