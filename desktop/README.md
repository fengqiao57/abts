# 阿B听书 · Windows 桌面版

独立桌面移植版，基于 [fengqiao57/abts](https://github.com/fengqiao57/abts) 的 MIT 开源实现。

## 使用

下载桌面版可执行程序，双击启动。便携压缩包需完整解压后运行 `ABTS Desktop.exe`，不要只移动其中的 EXE。
支持 Windows 10/11 x64。

- 搜索有声小说、评书、相声和广播剧，也可以直接粘贴作品 BV 号或完整 B 站链接。
- 打开详情后播放分集、加入书架、单集或批量缓存。
- 常驻播放条提供播放/暂停、上下集、前后 15 秒、进度、音量和 0.5–3 倍速。
- 播放面板可切换章节、设置播完本集暂停；月亮按钮可设置睡眠定时。
- 书架、收听进度、播放偏好和缓存队列保存到本机。重新启动后可以续播；已缓存的章节可离线播放。
- 可选哔哩哔哩扫码登录，登录信息使用 Windows 用户凭据保护加密保存。

## 全局快捷键

隐藏 / 取消隐藏默认 **Ctrl + Alt + H**；播放 / 暂停默认 **Ctrl + Alt + P**。

按一次隐藏窗口，同时从任务栏移除，不创建系统托盘图标，小说继续在后台播放。
再按一次相同快捷键只恢复任务栏入口，窗口保持最小化，不弹到桌面、不抢焦点。需要查看窗口时，自己点击任务栏。
窗口被其它软件盖住或普通最小化时，仍属于未隐藏状态，按隐藏快捷键会进入隐藏状态。
播放 / 暂停快捷键在其它软件处于前台、听书窗口隐藏时同样生效；重新启动后可从上次章节续播。

在「设置 → 全局快捷键」可分别设置两组组合键。
支持 Ctrl / Alt / Shift 等修饰键加字母、数字或 F1–F24。
两项不能使用相同快捷键；与其它软件冲突时会提示并保留原有可用组合。按 Esc 取消录制。

关闭窗口会退出程序；需要后台播放时请使用隐藏快捷键。
隐藏时重新双击程序也只恢复任务栏入口，不会直接弹出窗口。
使用新版前先正常退出旧版，再启动 1.0.2，避免旧版继续占用隐藏快捷键。书架、缓存和原隐藏快捷键会沿用。

1.0.2 在手动从任务栏恢复窗口时同步 Electron 的显示状态，避免原生最小化恢复后窗口与页面输入状态脱节。快捷键取消隐藏仍只恢复任务栏，不主动弹窗。

## 诊断日志

「设置 → 本地数据 → 诊断日志」可打开日志目录；也可按 Alt 展开菜单，从「诊断」记录窗口状态或打开日志目录。

发布版日志位于 `%APPDATA%\ABTS Desktop\logs\diagnostics.jsonl`。记录窗口切换、页面异常、无响应事件、心跳和点击计数，不记录搜索框内容、输入按键或登录凭据；日志只保存在本机，不自动上传。单文件约 1MB，最多保留当前和上一份。

遇到页面不能点击但音频继续时，记住大致时间，下次排查可按时间对照日志。旧版本未开启这类日志，无法补回之前的异常堆栈。
隐藏只涉及窗口、任务栏和托盘，进程仍能在任务管理器中看到。

## 数据与备份

发布版数据默认位于 `%APPDATA%\ABTS Desktop`，可在「设置 → 本地数据 → 打开目录」查看。

- `library.json`：书架、章节进度、关注列表、设置和下载队列。
- `library.json.backup`：上一次成功保存的备份。
- `session.dat`：Windows 加密保护的登录会话。
- `audio/`：离线音频和未下载完成的 `.part` 文件。

「导出备份」导出桌面版书架、作品、进度等元数据，不包含音频文件或登录凭据。
「导入备份」合并收藏和作品，并保留更新时间较新的收听进度。手机端数据格式不直接兼容。

## 构建

需要 Node.js 22.12+ 和 npm，首次安装依赖需要联网。

```powershell
npm ci
node node_modules/electron/install.js
npm test
npm run build
npm start
npm run package
```

桌面自动化检查：

```powershell
npm run test:desktop
npm run test:shortcuts
npm run test:window-input
```

源码中的 `tests/fixture.cjs` 仅用于开发测试，不进入发布包。
打包后的程序不需要安装 Node.js、Flutter 或 Android 模拟器。

## 范围

本版本保留主要听书工作流，采用适合桌面的独立界面，不是原手机界面的逐像素复制。
Android 专属的电池优化引导、通知栏服务、相册保存与 APK 更新功能没有移植。
音频资源、搜索结果和登录流程依赖哔哩哔哩公开服务；平台风控、下架、账号或地区限制可能影响访问。
没有绕过付费、版权或访问限制的功能，也不附带任何小说音频。
